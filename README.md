# Fichiers du workflow — Thème WordPress Diocèse de Ziguinchor

Workflow Claude Code pour la conversion du template Bootstrap "Story" en thème WordPress pour le Diocèse de Ziguinchor.

- `CLAUDE.md` : Contexte du projet + prompt d'amorçage à lire en début de chaque session.
- `SPEC.md` : Spécifications fonctionnelles et techniques (stack, modèle de données, architecture, écrans).
- `CONVENTIONS.md` : Règles de codage (nommage, sécurité, validation, structure des partials).
- `TODO.md` : Suivi des tâches par phase.
- `DECISIONS.md` : Journal des décisions techniques et bugs résolus.
- `BUGS_AND_ROADMAP.md` : Bugs corrigés et pistes d'évolution future.
- `CODE_SNAPSHOT.md` : Snapshot de code (généré automatiquement — ne pas modifier manuellement).
- `TASK_PROMPTS.md` : Prompts détaillés des tâches, prêts à être exécutés par Claude Code.
- `SETUP.md` : Guide d'installation (à ajouter manuellement si besoin — non fourni à ce stade).
